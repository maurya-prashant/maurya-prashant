### 💼 Featured Projects

#### 🩺 [Diagnyx — Agentic AI Medical Report Interpretation System](https://diagynx.netlify.app/)
`FastAPI` `LangGraph` `LangChain` `Groq LLM` `OCR` `Pydantic`
- Architected a **9-stage agentic AI pipeline** (ingestion → reasoning → synthesis) for automated medical report analysis using LangGraph state machines.
- Engineered a multi-step LLM workflow with iterative feedback loops, reducing hallucination rate through rule-based safety validation against clinical thresholds.
- Implemented multi-format document ingestion (PDF, DOCX, OCR images) with structured Pydantic schemas for consistent API responses.

#### 🔍 Lost & Found — AI-Powered Semantic Matching Microservices System
`Spring Boot` `FastAPI` `Sentence Transformers` `MySQL` `JWT` `REST`
- Designed a dual-service architecture (Spring Boot + FastAPI) with clean separation of business logic and AI inference layers.
- Built a semantic search engine using 384-dimensional embeddings and cosine similarity; hybrid ranking (semantic + category + fuzzy location) achieving **85% match accuracy**.
- Implemented JWT authentication with RBAC and real-time matching with automated email notifications.

#### 🩸 [BloodConnect — Geospatial Blood Donation Platform Backend](https://bloodconnect-app-eight.vercel.app/)
`Spring Boot` `PostgreSQL` `JWT` `Spring Security` `Haversine` `React`
- Built a RESTful backend with role-based access control (HOSPITAL / DONOR), enforcing compatibility rules and a 56-day donation cooldown.
- Implemented geospatial donor discovery using the Haversine formula for proximity-based matching, with automated real-time donor alerts.
- Secured the platform with JWT + Spring Security; integrated a React/Vite frontend consuming REST APIs.
